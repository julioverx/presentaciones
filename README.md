# Presentaciones Académicas Interactivas

Plataforma estática de diapositivas interactivas para exposiciones académicas. Desarrollada en HTML5, CSS ortogonal y JavaScript ligero, diseñada para ejecutarse en navegadores y proyectores.

---

## 📁 Estructura del Repositorio

```text
Diapositivas/
├── index.html                   # Catálogo / Hub de presentaciones
├── gemini.md                    # Manual de operaciones y directrices de diseño
├── Assets/
│   ├── Logo.svg                 # Logo institucional
│   ├── css/
│   │   ├── main.css             # Estilos del hub
│   │   └── slide-framework.css  # Motor visual ortogonal de diapositivas 16:9
│   └── js/
│       ├── presentations.js     # Catálogo de proyectos
│       └── slide-engine.js      # Motor de navegación de diapositivas
└── Proyectos/
    ├── Etica-de-la-Profesion/
    │   └── Slides-1/
    └── Teorias-de-la-Administracion/
        └── Slides-1/
```

---

## ⌨️ Atajos de Teclado durante la Exposición

| Tecla | Función |
| :--- | :--- |
| `→` / `Espacio` | Siguiente diapositiva |
| `←` | Diapositiva anterior |
| `F` | Alternar pantalla completa |
| `Home` / `End` | Primera / última diapositiva |
