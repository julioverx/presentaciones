# Carpeta Central de Ensayos (`Ensayos/`)

Coloca aquí los archivos de tus ensayos (en formato `.pdf`, `.docx` o `.md`) dentro de la carpeta correspondiente a la asignatura y al número real de las láminas (`Slides-1`, `Slides-2`, etc.):

```text
Ensayos/
├── Etica-de-la-Profesion/
│   └── Slides-1/
│       └── ensayo.pdf      <-- Coloca o reemplaza aquí tu ensayo actualizado para Slides-1
└── Teorias-de-la-Administracion/
    └── Slides-1/
        └── ensayo.pdf      <-- Coloca aquí el ensayo correspondiente a Slides-1
```

Cuando subas o actualices un ensayo en su carpeta `Slides-N`, solo avisa a Antigravity para sincronizarlo y publicarlo automáticamente en GitHub Pages.
